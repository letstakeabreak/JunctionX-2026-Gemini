## 폴더 구조

### `project/` — 출전 프로젝트 **STANDBY**

- Upstage 트랙 "Automate Paperwork" 출품작: 대본·큐시트를 분석해 blocking·quick-change·missing prop을 찾고 2D 무대에서 재생하는 AI 공연 프리플라이트 도구
- [`project/PRD.md`](project/PRD.md) 현재 제품 정의·3입력 simulation-verification 모델·48시간 MVP acceptance
- `README.md` 제품 정의·검증 규칙·노드 매핑·데모 구성
- `FINDINGS.md` 실제 큐시트에서 탐색한 초기 후보와 감사 주의 — ground truth 아님
- `DOMAIN.md` 공연 현업 워크플로우 리서치
